# GitHub Developer Analytics

A Python-based tool that analyzes a GitHub user's public repositories and generates useful developer statistics.

## Features

- Fetch GitHub user profile information
- Display followers and following
- Display public repository count
- Analyze repository languages
- Calculate language usage percentages
- Calculate total stars and forks
- Find the most-starred repository
- Find the most-forked repository
- Find the largest repository
- Find the most recently updated repository

## Technologies

- Python
- GitHub REST API
- Requests

## How It Works

1. Enter a GitHub username.
2. The program fetches the user's profile using the GitHub API.
3. It retrieves the user's public repositories.
4. The program analyzes repository data.
5. It displays the developer's GitHub statistics.
